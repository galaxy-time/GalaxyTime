# AU

The astronomical unit is a unit of length, roughly the distance from Earth to the Sun and approximately equal to 150 million kilometres or 8.3 light-minutes. The actual distance from Earth to the Sun varies by about 3% as Earth orbits the Sun, from a maximum to a minimum and back again once each year.

```
A	= 	unit distance
G	= 	gravitational constant
M_{\odot}	= 	solar mass
k	= 	numerical value of Gaussian gravitational constant
D	= 	time period of one day
```
